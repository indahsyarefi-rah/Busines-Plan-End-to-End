RADAR PELUANG - PANDUAN WINDOWS

1. PASANG NODE.JS SEKALI
   Buka https://nodejs.org/ dan unduh installer Windows versi LTS.
   Jalankan installer dengan pilihan standar. Anda tidak perlu memasang
   "Tools for Native Modules" atau paket build tambahan untuk aplikasi ini.

2. EKSTRAK ZIP
   Klik kanan radar-peluang-windows.zip > Extract All / Ekstrak Semua.
   Pilih folder yang mudah ditemukan, misalnya Documents/Radar-Peluang.
   Folder dist dan scripts harus tetap bersama MULAI-RADAR.cmd.

3. MULAI APLIKASI

   PILIHAN A - LEWAT VS CODE
   Gunakan cara ini bila klik dua kali launcher diblokir Smart App Control.
   Smart App Control boleh tetap aktif.

   a. Buka VS Code, pilih File > Open Folder.
   b. Pilih folder hasil ekstrak yang berisi folder scripts dan dist.
   c. Pilih Terminal > New Terminal (PowerShell).
   d. Salin baris berikut ke terminal, lalu tekan Enter:

      node .\scripts\serve-local.mjs

   e. Browser akan dibuka otomatis. Bila tidak, buka:
      http://127.0.0.1:5173

   Biarkan VS Code dan terminal tetap terbuka selama aplikasi dipakai.
   Jalankan perintah satu kali saja. Jangan menyalin tulisan PS C:\...>;
   tulisan tersebut hanya penanda lokasi terminal, bukan bagian perintah.
   Jika node tidak dikenali, tutup seluruh VS Code, lalu buka kembali
   setelah instalasi Node.js selesai.
   Jika muncul Cannot find module, periksa bahwa terminal berada di folder
   yang berisi scripts dan dist.

   Jika muncul jendela "Windows cannot find" tetapi terminal menampilkan
   "Radar Peluang siap digunakan", server tetap berjalan. Klik OK pada
   pesan Windows, lalu buka alamat di atas lewat Chrome atau Edge.
   Jangan jalankan server lagi selama server yang pertama masih berjalan.

   Untuk membuka browser sendiri tanpa pembukaan otomatis, gunakan:

      node .\scripts\serve-local.mjs --no-open

   PILIHAN B - LEWAT LAUNCHER
   Buka folder hasil ekstrak, lalu klik dua kali MULAI-RADAR.cmd.
   Bila Node.js belum terdeteksi, tutup terminal lalu jalankan kembali
   setelah instalasi Node selesai. Tidak perlu menjalankan sebagai administrator.

4. GUNAKAN DATABASE BAWAAN DAN BUAT LAPORAN
   Paket ini sudah memuat database gabungan: 105 masalah, 111 bukti,
   130 baris klasifikasi, dan progres 69 industri (64 berisi masalah).
   File CSV asli dan database pencarian ikut berada di dist/data.
   Tidak perlu mengimpor file, membuat akun, atau membeli API.

   a. Di halaman Proyek, pilih Cari database lokal atau Riset baru.
   b. Pastikan Sumber riset = Database lokal bawaan.
   c. Pilih sektor/industri atau ketik topik sederhana seperti bank atau BBM.
      Kosongkan topik dan pilih Semua industri untuk melihat seluruh 105 masalah.
   d. Untuk percobaan pertama, gunakan Kelompok konsumen = Konsumen umum,
      daerah kosong, dan periode Semua periode.
   e. Klik Mulai riset. Hasil yang cocok disalin sebagai proyek baru.
   f. Buka masalah untuk membaca ringkasan, ID asal, dan bukti sumbernya.
      Ringkasan sumber dari CSV bukan kutipan langsung. Tautan sumber
      membutuhkan internet; pencarian database tetap bisa tanpa internet.
   g. Periksa sumber dan isi alternatif, hipotesis peluang, atau catatan validasi
      yang masih kosong. Rencana validasi awal adalah saran sistem, belum dilakukan.
   h. Klik Ekspor untuk mengunduh Excel atau PDF. Pilih seluruh proyek atau
      satu masalah. Laporan menyertakan parameter, batasan, bukti, ID asal,
      dan rencana validasi. Hasil ini bukan bukti kelayakan atau keuntungan bisnis.

   Filter topik dan kata kunci mencocokkan teks, bukan analisis AI.
   Kata kunci tambahan dipisahkan koma dan semuanya harus cocok.
   Daerah dan konsumen mengikuti teks pada catatan. Aplikasi tidak menganggap
   masalah otomatis berlaku di daerah lain. Bahasa corpus adalah Indonesia.
   Periode memakai tanggal publikasi, bukan tanggal pemeriksaan. Sumber tanpa
   tanggal publikasi hanya dipertimbangkan pada Semua periode. Bila satu bukti
   dalam rentang, masalahnya masuk dan bukti lain tetap ditampilkan untuk konteks.
   Hasil kosong tidak berarti masalah tidak ada; coba kurangi filter.

   Data unggahan dan klaim klasifikasi/sumber belum diperiksa ulang oleh aplikasi.
   Target 200 masalah per industri BELUM terpenuhi. Alternatif solusi dan ide
   penawaran tidak tersedia dari CSV ini; Anda dapat menambahkannya sendiri.

   Pilih Sumber riset = Catatan manual untuk membuat proyek kosong sendiri.
   Tambahkan masalah, bukti, alternatif, ide, dan validasi sesuai hasil riset.
   Proyek demo memakai data ilustrasi terpisah.

   PENTING SAAT MEMPERBARUI PAKET:
   Hentikan server lama dengan Ctrl+C. Ekstrak ZIP baru dan jalankan dari folder
   baru itu, lalu muat ulang browser. Folder dist dan scripts harus tetap lengkap.
   Gunakan browser, profil, dan alamat 127.0.0.1:5173 yang sama agar proyek lama
   tetap terbaca. Database baru tidak menimpa proyek pribadi atau catatan lama.

4B. BUAT BUSINESS PLAN
   a. Cari masalah melalui database atau buka proyek riset Anda.
   b. Buka detail satu masalah, lalu klik Buat Business Plan.
   c. Background terisi sebagai draf dari salinan masalah dan bukti asal.
      Suntingan rencana tidak mengubah data riset sumbernya.
   d. Isi tahap 3 sampai 14 melalui menu tahap. Prototipe opsional.
      Setiap tahap memiliki analisis, sumber, asumsi, validasi, dan status.
      Semua isian tersimpan otomatis bersama proyek pada browser ini.
   e. Pada Financial Projection, isi semua asumsi angka. Angka kosong berarti
      belum diketahui, bukan nol. Untuk perantara, isi komisi per transaksi,
      bukan seluruh nilai transaksi. Proyeksi sederhana berjalan 12 bulan.
      Laba dan kas berbeda; jeda pembayaran memengaruhi arus kas.
      Kalkulator belum mencakup depresiasi, pinjaman/bunga, persediaan,
      atau rincian pajak. Skenario volume 70/100/130 persen adalah ilustrasi.
   f. Catat risiko beserta dampak, tanda peringatan, penanganan, dan penanggung jawab.
   g. Kerjakan Executive Summary terakhir. Tombol Susun draf ringkasan mengambil
      petikan isian, bukan analisis AI. Ringkas dan tinjau sendiri sebelum dipakai.
      Ringkasan berada paling depan pada laporan hasil ekspor.
   h. Pilih PDF atau Excel, lalu klik Ekspor business plan.
      Bagian yang kosong tetap ditandai belum tersedia, bukan dibuat-buat.

   Menu Business Plan menampilkan seluruh rencana. Satu masalah dapat memiliki
   beberapa rencana. Menghapus proyek sumber juga menghapus rencana di dalamnya.
   Ekspor dahulu sebelum menghapus proyek atau data situs/browser.
   Bila bagian lain berubah, bagian yang sudah terisi ditandai perlu ditinjau ulang.
   Pilih status tahap kembali setelah meninjau. Siap ditinjau tidak berarti
   rencana sudah tervalidasi atau usaha pasti layak/menguntungkan.
   KBLI dan izin harus diperiksa tersendiri; kode IDX-IC bukan pengganti KBLI.

5. MENGHENTIKAN APLIKASI
   Klik terminal yang MASIH menjalankan Radar Peluang, lalu tekan Ctrl+C.
   Setelah muncul kembali tulisan PS C:\...>, server di terminal itu
   sudah berhenti. Browser dan VS Code boleh ditutup.

   Tulisan ^C saat menekan Ctrl+C adalah normal, bukan pesan kesalahan.
   Jika PS C:\...> sudah muncul sebelum Anda menekan Ctrl+C, tidak ada
   aplikasi yang sedang berjalan di terminal tersebut. Server mungkin
   berjalan di terminal atau jendela lain.

   Untuk memakai lagi, buka folder yang sama dan jalankan:

      node .\scripts\serve-local.mjs

   Data browser tetap tersimpan ketika server dihentikan. Gunakan browser,
   profil, dan alamat yang sama saat membuka kembali. Tetap ekspor rutin.

6. JIKA PORT 5173 MASIH DIPAKAI
   Coba buka http://127.0.0.1:5173 terlebih dahulu. Jika Radar Peluang
   muncul, Anda dapat langsung menggunakannya; tidak perlu memulai server baru.

   Untuk menghentikan Radar Peluang yang masih berjalan di jendela lain,
   salin SELURUH tiga baris berikut ke terminal PowerShell, lalu tekan Enter:

      Get-CimInstance Win32_Process -Filter "Name = 'node.exe'" |
        Where-Object { $_.CommandLine -like '*serve-local.mjs*' } |
        ForEach-Object { Stop-Process -Id $_.ProcessId }

   Jika terminal menampilkan >>, lanjutkan menempelkan semua baris sampai
   lengkap, lalu tekan Enter. Perintah harus berakhir dengan tanda }.
   Perintah menargetkan proses Node yang menjalankan serve-local.mjs.
   Biasanya tidak ada pesan setelah selesai. Ini tidak menghapus data proyek.
   Jika tidak ada proses yang cocok, perintah tidak menghentikan aplikasi lain.

   Jika port tetap dipakai, mungkin port tersebut digunakan aplikasi lain.
   Jangan menghentikan proses yang belum dikenali. Catat pesan yang muncul
   untuk diperiksa sebelum menjalankan Radar Peluang kembali.

PENTING TENTANG DATA
- Gunakan browser dan profil yang sama, serta alamat 127.0.0.1:5173 yang sama.
- Gunakan jendela biasa. Mode Incognito/InPrivate dapat menghapus data ketika ditutup.
- Data tersimpan pada penyimpanan browser, bukan di folder ZIP, bukan di akun cloud.
- Menghapus data situs/browser dapat menghapus semua proyek. Ekspor rutin.
- Laporan Excel/PDF adalah dokumen keluaran; belum dapat diimpor sebagai pemulihan otomatis.
- Paket laptop mencari database bawaan secara offline dan mendukung catatan manual.
  Riset web baru dan analisis AI tidak aktif pada paket ini.
- Setelah Node.js terpasang dan paket diekstrak, aplikasi tidak membutuhkan unduhan
  npm, akun hosting, kartu pembayaran, atau koneksi internet untuk dibuka.
  Internet tetap diperlukan saat Anda ingin membuka tautan sumber di web.
- Paket hanya menerima koneksi dari laptop ini, bukan perangkat lain di jaringan.
- Port 5173 harus kosong. Jika sedang dipakai, tutup Radar Peluang yang sebelumnya.

Paket ini dibuat dari build aplikasi di workspace. Launcher .cmd disiapkan
untuk Windows; pengujian Windows langsung belum tersedia di lingkungan Linux ini.

  Untuk mencoba digital/BBM: Semua industri, daerah kosong, Konsumen umum,
  Semua periode. Muat ulang browser setelah memperbarui paket.
